# Aquavium.nvim

https://github.com/T-b-t-nchos/Aquavium.nvim

## what is Aquavium?

Aquavium.nvim is designed for use with a transparent terminal background
and features an aquarium-themed color scheme.


In addition to Neovim, we also provide color schemes for other software,
such as WezTerm(Aquatermium) and oh-my-posh(Aquaposh).

## features

  • Neovim 0.11+ support
  • Transparent terminal background support
  • Aquarium-themed color scheme
  • Support for other extra softwares. → github.com/T-b-t-nchos/Aquavium.nvim/tree/main/extras/

## installation

### In terminal

Please set opacity


### In Neovim

#### (Recommended Config)

vim.opt.winborder = "rounded"

#### Lazy.nvim


{
    "T-b-t-nchos/Aquavium.nvim",
    lazy = false,
    priority = 1000,
    config = function()
        local aquavium = require("Aquavium")

        aquavium.setup({
            -- your options here
        })

        vim.cmd("colorscheme Aquavium")
    end,
},

For more information, please refer to the README.md.

## support

### Neovim

Neovim 0.11+ is supported.

In addition, we support the following plugins:

  • blink.cmp
  • bufferline.nvim
  • dashboard-nvim
  • lazy.nvim
  • lualine.nvim
  • Markview.nvim
  • neo-tree.nvim
  • nvim-cmp
  • nvim-notify
  • nvim-treesitter-context

### Terminal

  • WezTerm
  • Windows Terminal

### Others

  • lazygit
  • oh-my-posh
  • yazi

Please check the README.md for the latest information.
